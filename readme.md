# 🐓 Куриная Империя (Chicken Impire) — v1.1.0 Release
---

Добро пожаловать в суровый экономический пиксельный симулятор выживания фермера в Куриной Империи! Управляйте ресурсами, торгуйте на улице и попробуйте не обанкротиться в лапах финансовой империи.

---

## ⚙️ Технический Стек / Разработка
* **Движок:** Godot Engine 3 (GDScript)
* **Платформы:** Windows Desktop, Android, Linux 64-bit
* **Архитектура UI:** Монолитная структура Control-узлов с бронированными флагами-предохранителями

## 🏦 Ключевые Фичи Версии v1.1.0 Release (Текущий Релиз)
* **Android:** Мобильный джойстик, поддерживается Android 5+
* **Цикл дня и ночи:** 1 реальная секунда - 30 игровых минут! 
* **Лиса:** Лиса вылазит ночью с 0 до 7 часов из норы, подкрадывается к курам и убивает их! Будьте осторожны!
* **Цыпа-гигачад:** Защитник от лисы, покупается в КуроТиндере!
* **Режим отладки:** Только для ПК! Чтобы включить запустите игру через терминал с флагом --mode=debug, в терминал посыпятся логи действий игрока! 

## 📦 Хронология Релизов (Вкладка Releases -> Assets)
* **v1.1.0 Release(Обновление хищности):** Хорошая, релизная версия с лисой, цыпой-гигачадом и фиксом багов!
* **v1.0.1 - v1.0.2 Release(Забагованные):** Локализация и поддержка Android, но в этих версиях обнаружены баги! Просьба установить 1.1.0 Release вместо этих версий
* **v1.0.0 Release(1-я Релизная):** Стабильная версия с главным меню, первая официально релизная
* **v1.2.1 unrelease (Последняя unrelease):** Стабильный бэкенд, фикс анимации fade, рабочий ПетухБанк.
* **v1.0.1 - v1.2.0 unrelease:** Исторические архивные сборки (скомпилированные `.exe` доступны в Assets, исходный код внутри репозитория обновлён до последней нерелизной версии v1.2.1).
