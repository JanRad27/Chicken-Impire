# 🐓 Куриная Империя (Chicken Empire) — v1.0.0 Release

Добро пожаловать в суровый экономический пиксельный симулятор выживания фермера в Куриной Империи! Управляйте ресурсами, торгуйте на улице и попробуйте не обанкротиться в лапах финансовой империи.

## ⚙️ Технический Стек / Разработка
* **Движок:** Godot Engine 3 (GDScript)
* **Платформа:** Windows Desktop
* **Архитектура UI:** Монолитная структура Control-узлов с бронированными флагами-предохранителями

## 🏦 Ключевые Фичи Версии v1.0.0 Release (Текущий Релиз)
* **Главное Меню**
* **Интерфейс «ПетухБанк» (ПЕБ):** Полноценное банковское приложение внутри игры! Личный кабинет, просмотр баланса, жёлтые кредитные карты с магнитной лентой и кастомный Roboto-шрифт.
* **Бронированная Система Верификации:** Кастомный валидатор ввода в `LineEdit` на базе жёсткого белого списка символов `['1', '2', '3'...]`. Полная защита экономики от ввода букв, минусов, точек и нулевых кредитов!
* **Динамический Расчёт Долга:** Реализовано покадровое списывание процентов по кредиту в реальном времени с автоматической отправкой неплательщиков в оранжевую тюремную форму.
* **Глобальный Фикс Века:** Полностью аннигилирован баг двойного покадрового клика в Больнице. Грабительская строчка `money -= 50` внутри анимации затемнения экрана `fade()` успешно ликвидирована!

## 📦 Хронология Релизов (Вкладка Releases -> Assets)
* **v1.0.0 Release(Текущая):** Стабильная версия с главным меню, первая официально релизная
* **v1.2.1 unrelease (Прошлая):** Стабильный бэкенд, фикс анимации fade, рабочий ПетухБанк.
